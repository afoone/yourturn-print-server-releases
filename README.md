# YourTurn Print Server — instaladores

Este repositorio solo publica los instaladores de **YourTurn Print Server**, la aplicación que
imprime los tickets de [yourturn.space](https://www.yourturn.space) en impresoras térmicas.
No contiene código fuente.

Descarga la última versión en [Releases](../../releases/latest):

- **Windows:** `YourTurn-Print-Server-Setup-<versión>.exe`. Se actualiza sola a partir de la 1.1.0.
- **macOS:** `YourTurn-Print-Server-<versión>-arm64.dmg` (Apple Silicon) o `-x64.dmg` (Intel).
  Por ahora las actualizaciones en Mac se instalan a mano.
